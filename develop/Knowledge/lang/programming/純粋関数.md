**純粋関数**（じゅんすいかんすう、pure function）とは、同じ入力に対して常に同じ出力を返し、副作用を持たない関数のことである。

## 概要
純粋関数は、副作用を持たず、同じ入力に対して同じ出力を出す。  
ここでの副作用とは、外部の値の状態を変更したり、外部の状態に依存したりすることを指す。例えばグローバル変数の変更や、ファイル等のIO、標準出力への表示などが副作用に該当する。

純粋関数では、入力が同じであれば出力も同じになり、関数の動作の予測やデバッグが簡単になる。
### 参照透過性
同じ入力に対して同じ出力を返すことを、**参照透過性がある**という。数学で扱う関数$f(x)=x^2+3x+1$などは参照透過性があると言える。

## コード例
TypeScriptで適当に書いた。

```ts
function average(arr: number[]) -> number {
	let sum = 0;
	for (let v of arr) {
		sum += v;
	}
	return sum / arr.length;
}
```

つまりは関数内でIO系の処理やグローバル変数へのアクセスを行っていなければ純粋関数だと言える。

ただし；

```csharp
public class MyClass {
	private myNumber;
	
	public MyClass(int num) {
		myNumber = num;
	}
	
	public int AverageMultiplied(int[] arr) {
		var sum = 0;
		foreach (v in arr) {
			sum += v;
		}
		return sum / arr.Length * myNumber;
	}
}
```

このようなクラス内の値を読んでいる場合はそれは純粋関数とは言えない（当然）。
